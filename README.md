# 弹幕画板 · Danmaku Board

一块会**生长成画**的霓虹弹幕墙 🌲

文字和涂鸦发射出去**不会消失**——它们以霓虹形态在画布里持续滚动、回卷、漂移，越积越多，最后变成一幅会呼吸、不断生长的动态壁画。滚动是运动方式，「画板」是它最终长成的样子。

> 参赛作品 · 1024 造物挑战（程序员节给自己搭个玩具）

## ✨ 特性

- **文字 + 手绘双通道**：打字回车发射彩色霓虹弹幕；切到 ✏️ 涂鸦在画布上随手画，松手后这条笔迹也会变成会流动的弹幕。
- **4 种滚动模式**：横向回卷 / 纵向回卷 / 波浪漂移 / 螺旋扩散（螺旋会持续向外生长，最像「一幅画」）。
- **景深层次**：每条弹幕有远/近坐标，远景更小、更慢、更淡、藏在底层被近景压住；近景更大、更快、更亮、浮在上层，真正的空间纵深。
- **实时可调清晰度**：拖尾强度、发光强度、整体透明度都能拉——弹幕再多也不糊成一片（解决散光/遮挡）。
- **关键词特效**：输入「烟花 / 爱心 / 雪 / 赞」就地炸出对应粒子 + 音效。
- **WebAudio 合成音效**：发射「嗖」、特效「砰」，无需任何音频文件；🔊 一键静音。
- **📸 截图导出 PNG** / **⏺ 录制导出 WebM**，直接当参赛素材。
- **🎵 歌词同步**：选一首歌 + 丢个 LRC（或直接粘贴），歌词按时间轴逐行变成金色前景弹幕飞出。
- **🌐 零登录多人房间**：别人收到邀请链接点开即进，以弹幕形式一起聊；房主可开「公开聊天」或「KTV 演唱会」（歌词实时同步给所有人）。

## 🚀 本地运行

### 单人版（纯前端 · 零依赖）
直接用浏览器打开 `index.html` 即可，不需要任何服务器。

### 多人房间（需中继服务）
```bash
cd server
npm install
PORT=8787 node server.js
```
然后浏览器打开 `http://localhost:8787`，点 🌐 填房间名进入；把「🔗 复制邀请链接」发给朋友，对方点开即进房以弹幕聊天。

## 📁 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 完整版（含多人房间功能） |
| `deploy/index.html` | 投稿/部署版（纯单人体验，已隐藏房间入口） |
| `server/server.js` | 零依赖 WebSocket 中继：房间 / 房主 / 模式 / 弹幕广播 / 在线人数 |
| `server/package.json` | 仅依赖 `ws` |

## 🛠 技术栈

- 前端：纯 HTML5 Canvas + 原生 JS，**零框架、零构建**。
- 多人中继：Node.js + `ws`（零其他依赖）。
